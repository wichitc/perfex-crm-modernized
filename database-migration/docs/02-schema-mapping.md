# Phase 2: Schema Mapping Specification

## Table Name Preservation Strategy
To guarantee 0% application regression, table names are mapped 1-to-1:
- `tblclients` -> `tblclients`
- `tblinvoices` -> `tblinvoices`
- `tblstaff` -> `tblstaff`
- `tblleads` -> `tblleads`
- `tblestimates` -> `tblestimates`
- `tblprojects` -> `tblprojects`
- `tbltasks` -> `tbltasks`

## Primary Key Mapping
- MySQL `INT AUTO_INCREMENT` -> PostgreSQL `INTEGER GENERATED BY DEFAULT AS IDENTITY`
- MySQL `BIGINT AUTO_INCREMENT` -> PostgreSQL `BIGINT GENERATED BY DEFAULT AS IDENTITY`

## Foreign Key Mapping
- All foreign keys retain exact `ON DELETE CASCADE` and `ON DELETE RESTRICT` semantics.
