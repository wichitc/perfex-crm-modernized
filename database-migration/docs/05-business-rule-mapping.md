# Phase 2: Business Rule & Constraint Mapping

1. **Auto-Increment Primary Keys**: Handled by PostgreSQL `GENERATED BY DEFAULT AS IDENTITY`.
2. **Default Value Rules**: Preserved standard defaults (`0`, `1`, `CURRENT_TIMESTAMP`, `NULL`).
3. **Monetary Precision**: All monetary values use `NUMERIC(15,2)` to avoid precision loss.
4. **Encoding & Thai Language**: UTF-8 character encoding enforced across schema and database connection strings.
