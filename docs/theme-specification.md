# Theme Specifications - Perfex CRM

## Authentic Theme Palettes & Multi-Theme Matrix

Perfex CRM features 6 signature color themes. The modernized Next.js frontend implements dynamic theme switching matching the legacy `multi-theme-for-perfex-crm` module.

---

### 1. Perfex Classic Teal (Default)
- **Primary Color**: `#28b8da`
- **Sidebar Background**: `#25292e`
- **Header Background**: `#1e293b`
- **Active Badge**: `rgba(40, 184, 218, 0.1)` with `#28b8da` text
- **CSS Class**: `data-perfex-theme="teal"`
