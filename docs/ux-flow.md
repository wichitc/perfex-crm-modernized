# User Experience & Journey Flow - Perfex CRM

## Core User Journeys & Workflows

### Journey 1: Client Account Onboarding
```text
Login Screen -> Dashboard -> Clients Directory -> Add Client Modal -> Save Client -> View Profile & Contacts
```

### Journey 2: Lead Conversion Pipeline
```text
Leads Kanban Board -> Drag Lead to 'Proposal Sent' -> Click 'Convert to Client' -> Lead Conversion Wizard -> Generate Invoice
```

### Journey 3: Invoice Issuance & Payment Recording
```text
Invoices List -> Click 'Create Invoice' -> Select Line Items & Rates -> Save Invoice -> View Invoice Detail -> Click 'Record Payment' -> Generate Receipt PDF
```

### Journey 4: Strategic Account SWOT Planning
```text
Account Planning -> Select Enterprise Client -> Input Strengths/Weaknesses/Opportunities/Threats -> Save SWOT Matrix -> Export PDF Report
```
