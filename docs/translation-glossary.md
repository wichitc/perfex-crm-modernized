# Enterprise Translation Glossary & Terminology Dictionary

## Business Terminology Standards

| Concept / Domain Key | Thai Standard (ไทย) | English Standard | Usage Rules / Context |
| -------------------- | ------------------ | ---------------- | --------------------- |
| `customer` | ลูกค้า | Customer | Primary enterprise customer record |
| `client` | ลูกค้า | Client | Directory & client account |
| `lead` | ผู้มุ่งหวัง | Lead | Qualified sales lead / prospect |
| `pipeline` | กระบวนการขาย | Sales Pipeline | Lead/opportunity stages |
| `invoice` | ใบแจ้งหนี้ | Invoice | Billing invoice document |
| `estimate` | ใบประเมินราคา | Estimate | Price quote / estimate |
| `proposal` | ข้อเสนอ | Proposal | Customer project proposal |
| `accounting` | บัญชีและการเงิน | Accounting & Finance | Ledger, GL, journal entries |
| `ledger` | บัญชีแยกประเภท | General Ledger | Chart of accounts & transactions |
| `warehouse` | คลังสินค้า | Warehouse | Stock location & warehouse management |
| `inventory` | สินค้าคงคลัง | Inventory | Stock inventory items & SKUs |
| `purchase` | การจัดซื้อ | Purchase Management | POs & vendor purchases |
| `supplier` / `vendor` | ผู้จัดจำหน่าย | Supplier / Vendor | External vendor / supplier |
| `recruitment` | การสรรหาพนักงาน | Recruitment | Candidate recruitment pipeline |
| `employee` / `staff` | พนักงาน | Employee / Staff | Internal staff members |

| `account_planning` | การวางแผนบัญชีลูกค้า | Account Planning | Key account strategy & targets |
| `settings` | ตั้งค่าระบบ | System Settings | Global configuration |
| `approval` | การอนุมัติ | Approval | Workflow approval stage |
| `status.draft` | ร่าง | Draft | Uncommitted document state |

| `status.approved` | อนุมัติแล้ว | Approved | Final approved state |
| `status.rejected` | ไม่อนุมัติ | Rejected | Rejected workflow state |
| `status.cancelled` | ยกเลิก | Cancelled | Voided or cancelled state |
| `status.completed` | เสร็จสิ้น | Completed | Finished state |
