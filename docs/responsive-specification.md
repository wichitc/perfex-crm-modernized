# Responsive Specifications - Perfex CRM

## Breakpoints & Adaptive Layout Rules

| Device Breakpoint | Width (px) | Sidebar Behavior | Grid Layout Adjustment |
| :--- | :--- | :--- | :--- |
| **Desktop (Large)** | `>= 1280px` | Fixed 280px Sidebar Expanded | 4-Column KPI Cards, 2-Column Main View |
| **Laptop / Desktop** | `1024px - 1279px` | Fixed 280px Sidebar Expanded | 2-Column KPI Cards, 1-Column Charts |
| **Tablet** | `768px - 1023px` | Collapsible Off-Canvas Drawer | 2-Column KPI Cards, Horizontal Scroll Tables |
| **Mobile** | `< 768px` | Hidden Drawer with Overlay Toggle | 1-Column KPI Cards, Stacking Kanban Columns |
